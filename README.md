# 예약정리 — 문자 붙여넣기 예약 장부 (PWA)

받은 예약 문자를 그대로 붙여넣으면 현장·날짜·시간·이름·연락처로 자동 분리해
목록과 캘린더에 정리해 주는 개인용 앱입니다.

## 사용 방법

1. 홈페이지 예약이 접수되면 휴대폰으로 오는 문자를 **전체 복사**
2. **문자 붙여넣기** → 붙여넣고 **문자 분석** → 자동 분리된 내용 확인(수정 가능) → **저장**
   - **메모** 칸에 담당 메모를 함께 남길 수 있습니다
3. **목록** 탭 (3칸 구성):
   - **예정된 예약** — 당일이 맨 위, 방문 날짜 빠른 순. 오른쪽 체크 버튼으로 **방문완료 / 방문취소** 지정
   - **지나간 예약** — 날짜가 지난 예약 + **취소 처리한 예약**(취소 표시). 캘린더에는 계속 남습니다
   - **방문 완료** — 방문한 손님 기록 + **후기 작성** (후기 버튼으로 작성·수정)
4. **캘린더** 탭: 날짜별 예약 자동 표시(점·시간, 취소는 회색 점), 날짜를 누르면 그날 예약 보기
5. 화면이 넓으면(PC/태블릿) 목록 옆칸에 캘린더가 함께 표시됩니다

## 로그인 (Supabase 계정)

- 첫 화면에서 **회원가입**: 아이디는 자유롭게, 비밀번호는 **6자 이상**
- 예약 기록은 **계정별로 분리** 저장되며, 로그인 상태는 앱을 닫아도 유지됩니다
- 상단 **[로그아웃]** 으로 계정 전환

> Supabase 대시보드 → Authentication → Sign In / Providers → Email →
> **Confirm email 을 OFF** 로 설정해야 이메일 확인 없이 바로 가입·로그인됩니다.

## 설치 (PWA)

- 상단 **[앱 설치]** 버튼 (안드로이드) / 아이폰은 사파리 **공유 → 홈 화면에 추가**
- 설치하면 아이콘으로 실행되고, 오프라인에서도 앱이 열립니다

## 데이터 보관

기록은 로그인한 계정 단위로 **이 폰의 브라우저 저장소**에 저장됩니다.
브라우저 데이터를 삭제하면 기록도 사라지니, 주기적인 백업을 권장합니다
(백업 UI는 로그인 도입과 함께 다음 버전에서 재제공 예정).

## 실행/배포

정적 파일만 있으면 됩니다 (서버 불필요):

```
index.html      앱 전체 (화면+로직, Supabase 로그인 포함)
manifest.json   앱 정의 (이름·아이콘·색상)
sw.js           오프라인 실행 관리자
icon-192/512.png  앱 아이콘
```

- 로컬: `python3 -m http.server 8080` 후 접속
- 무료 배포: Netlify Drop, Vercel, GitHub Pages 등에 폴더 업로드
